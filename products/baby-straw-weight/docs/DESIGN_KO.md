# LV-2602 추빨대 추 — 설계 설명 (rev2)

## 피드백 반영

| 요청 | 반영 |
|------|------|
| 추 모양 크게 바꾸지 말 것 | 원형과 같은 **납작 타원** 유지 (둥근 물방울형 폐기) |
| 하단으로 움직여 우유 흡입 | **바닥면(-Z)에 흡입 구멍 3개** + 관통 보어 |
| 아이들이 좋아할 만한 / 세척 용이 | 부드러운 캡슐 실루엣, 막힌 공동 없이 통수·플러시 |
| 플라스틱 젖병과 마찰 최소 | 상·하면 **크라운 곡면** → 접촉 패치 축소, 모서리 라운드 |
| 연결부 최대한 단순 (세척) | **Ø4.5 직선 + 테이퍼만**, 리브/비드 제거 |

## 왜 납작 타원인가

젖병 바닥·벽면을 따라 추가 미끄러져야 합니다.  
납작한 형태는 무게중심이 낮고, 구형보다 병 안에서 **구름/미끄럼이 예측 가능**하며 원형 제품과도 일치합니다.

## 저마찰 디테일

- 완전 평면 상·하면은 실리콘-플라스틱 면접촉으로 달라붙기 쉬움  
- 약한 크라운(볼록)으로 **점/선 접촉**에 가깝게 만들어 드래그 감소  
- 외부 홈·돌기·텍스처 없음

## 연결부

- 외경 **4.5 mm** 고정 (바디만 부피 튜닝)  
- 선단 ≈Ø4.1 → Ø4.5 테이퍼로 호스 삽입 용이  
- 고정력: 실리콘 호스 내경이 스템보다 약간 작을 때의 탄성 압착 + 삽입 길이 9 mm  
- 리브가 필요하면 양산 시 **아주 낮은 단일 비드**만 옵션으로 추가 가능 (기본은 무리브)
