# LV-2602 추빨대 추 — 디자인 설명

## 요구사항 반영

| 요구 | 반영 |
|------|------|
| 아기용, 더 예쁜 형태 | 이슬방울(Dewdrop) 실루엣, 전면 라운드·부드러운 crest |
| 세척 편함 | 전면 오픈 인테이크 + Y/Z 플러시 포트 + Ø2.2 관통 보어 |
| 실리콘 비중 1.8, 무게 9 g | 순부피 ≈ 5.0 cm³ 튜닝 (실측 ≈ 8.99 g) |
| 전체 실리콘 | 단일 솔리드 실리콘 파트로 모델링 |
| 연결부 외경 4.5 mm | 스템 OD 실측 **4.5 mm** 유지 (바디만 부피 조정) |
| 호스 연결 쉬움 + 고정 | 선단 테이퍼(≈Ø3.9→4.5) + Ø5.4 이중 리브 |

## 치수 요약 (mm)

- 전체: 약 40.8 (L) × 21.2 (W) × 16.3 (H)
- 바디 half-axis: Rx 15.4 / Ry ≈ 10.0 / Rz ≈ 7.9
- 스템: Ø4.5 × L11, 리브 Ø5.4 × 2
- 음용 보어: Ø2.2

## 금형/양산 메모

1. 파팅 라인은 X축(길이) 대칭 평면(XY 또는 XZ) 권장
2. 리브는 금형 빼기 방향과 맞춰 undercut 최소화 — 필요 시 리브 각도를 barb(삽입 방향 완만 / 이탈 방향 급)로 조정
3. 식품 등급 실리콘, Shore A 40–60 권장 (너무 무르면 리브 고정력↓, 너무 硬하면 호스 삽입↓)
4. 호스 내경 스펙을 확정한 뒤 리브 OD(현재 5.4)를 ±0.1–0.2 미세 조정 가능

## 기존 참고 STL

업로드된 `LV-2602-001/002`는 약 **2.93 cm³ (~5.3 g)** 수준으로 목표 9 g에 못 미쳤고, 메시가 watertight하지 않아 양산용 CAD로 부적합했습니다. 본 디자인이 그 자리를 대체합니다.
